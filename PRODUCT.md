# 御神籤 — 오늘의 오미쿠지

## Platform
Mobile-first web for Korean readers opening physical NFC charms.

## Stack
Plain HTML, CSS, JavaScript and static JSON; GitHub Pages via Actions. No accounts, user-entered personal data, external APIs, runtime LLM, analytics or externally hosted fonts. Classic browser bundle supports direct-file preview.

## Confirmed scope
Daily KST deterministic draw by version and ID; seven grades (大凶 added at 1%); eight topics; folded-paper reveal; same-day bypass; midnight reset; reduced motion; error handling.

## Content
v2: 280 main cards and 1,680 topic entries. Original 48 main and 144 topic entries remain unchanged under v1/. Additions use 216 situation/action pairs, 32 motifs with six authored interpretations, and grade-specific voice. Shared sentence parts are intentional; complete poems, guidance and topic readings have no duplicates.

## Brand commitments
Dark ground, warm paper, ink typography, vermilion seal, warm rules, one central sheet and horizontal Korean. Preserve the user-pinned existing design.

## IDs
No ID draws with a random per-browser ID kept in local storage (falls back to one shared demo ID if storage is blocked). Case-sensitive ASCII letters, digits, underscore and hyphen, 6–64 characters. IDs identify charms, not authenticated people.
